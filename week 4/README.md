# Неделя 4. Взаимодействие между двумя Pluto SDR на Си

## 1. Теория: Инициализация двух устройств и дуплекс

### 1.1. Адресация двух SDR по USB
При подключении двух устройств Adalm Pluto к одному компьютеру стандартный URI `usb:` не позволяет выбрать конкретное устройство. Для явного обращения к каждому SDR используются уникальные идентификаторы на шине USB (например, `usb:3.19.5` и `usb:3.18.5`).

### 1.2. Разделение частот (FDD)
Для передачи данных между двумя SDR без взаимного забития собственных приёмных трактов используется частотное разделение:
* **Устройство 1 (режим Tx)**: передача на частоте 800 МГц, приём на частоте 750 МГц.
* **Устройство 2 (режим Rx)**: приём на частоте 800 МГц, передача на частоте 750 МГц.

Передача пакетов осуществляется с использованием аппаратных временных меток SoapySDR с флагом `SOAPY_SDR_HAS_TIME` со сдвигом на 4 мс относительно текущего времени приёмного буфера.

## 2. Практика: Настройка и запуск программы

### 2.1. Доработка `main.c` для двух устройств
В коде реализована структура конфигурации `AppConfig` и выбор роли устройства через аргумент командной строки:
* При запуске `./main 0` - устройство настраивается с URI `usb:3.19.5`, TX = 800 МГц, RX = 750 МГц, сохраняет данные в `Txdata.pcm`.
* При запуске `./main 1` - устройство настраивается с URI `usb:3.18.5`, TX = 750 МГц, RX = 800 МГц, сохраняет данные в `Rxdata.pcm`.

Отправка пакетов выполняется на каждом чётном буфере:
```c
if (buffers_read % 2 == 0 && buffers_read > 0) {
    printf("buffers_read: %d\n", buffers_read);
    flags = SOAPY_SDR_HAS_TIME;
    int st = SoapySDRDevice_writeStream(sdr, txStream, (const void * const*)tx_buffs, tx_mtu, &flags, tx_time, timeoutUs);
    if ((size_t)st != tx_mtu) {
        printf("TX Failed: %i\n", st);
    }
}
```

### 2.2. Скрипт визуализации `readrx.py`
Скрипт открывает файл `./build/Rxdata.pcm`, читает 16-битные квадратурные отсчеты $I$ и $Q$ и строит график.

## 3. Результаты работы

Программа была запущена на приёмном SDR (`./main 1`) во время работы передающего SDR (`./main 0`). Принятые данные были записаны в `Rxdata.pcm` и отображены с помощью `readrx.py`.

![График принятых сигналов от второго SDR](../screens/chart%202%20sdrs.png)

По факту работы:
* На графике зафиксированы **4 периодические пачки импульсов** от передающего SDR (на буферах №2, №4, №6 и №8).
* Амплитуда полезного сигнала подскакивает с уровня шума (около $\pm 1\dots 2$) до значений $\pm 10\dots 11$.
* Сигнал между двумя SDR успешно передан и принят по радиоканалу.
